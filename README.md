# شات‌دان واحد بخار

نرم‌افزار اندرویدی نمایش و اجرای تایمر شات‌دان واحد بخار بر اساس جدول مرجع (۱۹ نقطه از 0:00 تا 3:00).

## امکانات
- نمایش جدول کامل داده‌های شات‌دان
- تایمر اجرای شات‌دان از ۰ تا ۱۸۰ دقیقه (شروع / توقف / بازنشانی)
- برجسته‌سازی نقطه هدف فعلی بر اساس زمان سپری‌شده
- نمایش فشار بخار اصلی، بار واحد و دمای بخار اصلی در نقطه فعلی
- امکان انتخاب دستی یک ردیف از جدول برای مشاهده جزئیات
- هشدار ظاهری در پایان برنامه
- حفظ وضعیت تایمر در چرخش صفحه
- رابط کاربری فارسی و راست‌چین

## ساخت پروژه
1. Android Studio (نسخه Hedgehog یا جدیدتر) را نصب کنید.
2. پروژه را باز کنید: File > Open > پوشه `steam-shutdown-app`
3. صبر کنید تا Gradle Sync تمام شود.
4. برای ساخت APK: Build > Build Bundle(s)/APK(s) > Build APK(s)
5. فایل خروجی در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نصب
- فایل APK را روی گوشی اندرویدی (حداقل اندروید ۵) منتقل و نصب کنید.
- برای نصب، فعال‌سازی «نصب از منابع ناشناس» لازم است.

## نکات فنی
- نام بسته: `com.nirocontrolarian.steamshutdown`
- Kotlin + XML (بدون کتابخانه اینترنتی اضافه؛ فقط androidx/material استاندارد)
- حداقل SDK: 21، هدف: 34
- آیکون به‌صورت برنامه‌نویسی‌شده تولید شده و به فایل بیرونی نیاز ندارد.


## مراحل آپلود در گیت‌هاب و ساخت APK

1. در صفحه اصلی مخزن گیت‌هاب روی دکمه **Add file → Upload files** کلیک کنید.
2. **تمام فایل‌ها و پوشه‌های پروژه** را مستقیماً در **ریشه مخزن (root)** آپلود کنید؛ یعنی `README.md`، `build.gradle.kts`، `settings.gradle.kts`، `gradle.properties` و پوشه‌های `app/` و `.github/`.
3. نکته مهم: پوشه `.github` به صورت پیش‌فرض مخفی است. اگر سیستم‌عامل آن را آپلود نمی‌کند، ابتدا گزینه نمایش **فایل‌های مخفی (hidden files)** را فعال کنید، یا فایل `build-apk.yml` را دستی با مسیر `.github/workflows/build-apk.yml` از طریق **Add file → Create new file** بسازید و محتوای آن آن را Paste کنید.
4. پس از آپ همه فایل‌ها روی **Commit changes** کلیک کنید. با Push شدن کد، ورک‌فلو **Build Android APK** به‌طور خودکار اجرا می‌شود (یا از تب **Actions** با **Run workflow** به‌صورت دستی اجرا کنید).
5. پس از پایان موفق اجرا، وارد تب **Actions** شده، روی اجرای انجام‌شده کلیک کنید و از بخش **Artifacts** فایل **steam-shutdown-debug-apk** را دانلود کنید.
6. فایل ZIP دانلودشده را **Extract (استخراج)** کنید تا فایل `app-debug.apk` به دست آید.
7. فایل `app-debug.apk` را به گوشی اندروید منتقل کرده و برای نصب، اجازه **Install unknown apps** را در تنظیمات بدهید و سپس APK را نصب کنید.
